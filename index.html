แอปพลิเคชัน: Mycraft Assistant · โดเมน: mycraftbot.cloud · อัปเดตล่าสุด: 12 ตุลาคม 2026

1. แอปนี้คืออะไร

Mycraft Assistant เป็นเครื่องมือผู้ช่วยส่วนตัวที่พัฒนาและใช้งานโดยเจ้าของบัญชีเพียงรายเดียว เชื่อมต่อข้อมูลผ่าน Google OAuth (Gmail, Calendar, Drive, Docs, Sheets, Contacts) เพื่อแสดงข้อมูลสรุปและช่วยเหลืองานส่วนตัวของผู้ใช้เท่านั้น

Mycraft Assistant is a personal assistant tool operated solely by its owner. It connects to the owner's own Google account via OAuth to provide personal summaries and productivity support.

2. ข้อมูลที่เข้าถึง

แอปขอสิทธิ์เข้าถึงเฉพาะข้อมูลของบัญชีผู้ใช้ที่อนุญาต (authorizer) เอง ได้แก่: ข้อความและรายการใน Gmail, รายการใน Google Calendar, ไฟล์ใน Drive/Docs/Sheets (อ่านและแก้ไขเมื่อผู้ใช้สั่ง), และรายชื่อ Contacts (อ่านอย่างเดียว) ข้อมูลเหล่านี้ใช้เพื่อประมวลผลตามคำขอของผู้ใช้เท่านั้น

3. การใช้และเก็บรักษาข้อมูล

  • ไม่ขาย ไม่แชร์ และไม่ส่งข้อมูลต่อให้บุคคลที่สาม
  • ไม่ใช้ข้อมูลเพื่อโฆษณาหรือโปรไฟล์ติ้ง
  • token การเข้าถึงเก็บบนเซิร์ฟเวอร์ส่วนตัวของผู้ใช้ และสามารถเพิกถอนได้ทุกเมื่อที่ myaccount.google.com/permissions
  • ลบข้อมูลหรือถอนการเชื่อมต่อได้ตลอดโดยไม่มีค่าใช้จ่าย

4. ผู้ใช้กับข้อมูล

Google API data is handled only to provide the app's features to the authorizing user, in compliance with the Google API Services User Data Policy (limited use).
